# Model Evaluation Report

## Objective
Predict house prices from property characteristics.

## Preprocessing
- Duplicate removal
- Missing value imputation
- Standard scaling for numerical variables
- One-hot encoding for categorical variables

## Models
1. Linear Regression
2. Gradient Boosting Regressor
3. Random Forest Regressor

## Metrics
- MAE
- RMSE
- R²

The Streamlit dashboard allows training each model and displays its evaluation results.
